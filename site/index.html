Vespasian The Weight Space
Editing Assistant.

Vespasian is an open-source weight space editing tool for small language models. A frontier model proposes direct tensor changes, evaluates them against your dataset and retains the best checkpoint. Run it in your terminal or on Hugging Face.

02 · The method

The weight hill climb.

Weight space programming through direct tensor edits.

A frontier language model inspects the target model and its answers, then proposes a bounded weight alteration. Direct tensor operations and forward evaluation drive the search. Validation scores select the next step.

Explore the search loop ↗
  1. 01

    Set a direction

    Define the behaviour, connect edit and validation examples, then choose the metric and capabilities to preserve.

  2. 02

    Apply a weight edit

    The editor inspects tensors and activations, selects a supported operation and proposes its parameters. Vespasian applies the bounded change directly to the weights.

  3. 03

    See the result

    Vespasian generates answers and measures the objective alongside copying, arithmetic, JSON or MMLU health checks. Optional regression limits reject edits that reduce these scores too far.

  4. 04

    Keep what works

    Improved validation scores retain a candidate. Rejected edits are restored. Export the best checkpoint or a replayable weight patch with its measurements and optional editor trajectory.

06 · Working with Vespasian

Weight editing
in practice.

Choose the model, data and measurements that fit the behaviour you want to change.

What is weight space editing?

Weight space editing changes a neural network’s parameters to alter its behaviour. Vespasian uses an LLM-guided hill climb: a frontier model inspects weights and outputs, proposes direct tensor surgery, then uses measured results to guide its next edit.

Which models can I edit?

Vespasian supports Qwen3.5-0.8B and Gemma 3 1B. The terminal also accepts Hub model IDs and local checkpoints with compatibility checks. The hosted workbench offers models loaded by its operator.

Can I edit style and tone?

Yes. Use a text corpus for unconditional generation, or prompts scored against a style goal. Paired examples support reference-answer tasks such as maths and factual responses. Dataset modes and field mapping ↗

Can I use it in the browser?

The Hugging Face Space runs model evaluation on ZeroGPU. Sign in with Hugging Face to access private datasets and save results to the Hub. Public datasets are available without signing in.

How do the editor and budget work?

The terminal connects to Codex or Claude CLI sessions, or OpenAI/Anthropic APIs. The browser accepts an OpenAI or Anthropic API key. Set a USD budget for frontier inference and follow tracked spend. CLI login sessions report estimated cost between calls.

What can I save after a run?

Export a full model checkpoint or a replayable weight patch, together with evaluation scores and optional editor trajectories. Download the files or publish selected results to a public or private Hugging Face repository.
